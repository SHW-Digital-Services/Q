Mission & Values

The foundation of every design decision we make.

Our Mission

"Your private space for LGBTQ+ wellbeing and personal reflection. We provide intelligent support, safe conversations, resources, and guidance for LGBTQ+ individuals and allies."

Q

Secure & Private

Privacy is part of the product experience: clear controls, high-privacy defaults, local AI where available, and honest boundaries about cloud features.

Built with Empathy

Our intelligence features exist to support, not dictate. Responses must always be compassionate, supportive, and culturally competent regarding LGBTQ+ issues.

Connected Community

While private, we also facilitate connection to peer knowledge and safe, inclusive community resources when the user is ready.

Tone of Voice

How we speak to our users in UI copy, marketing, and AI responses.

We Are

  • Welcoming: "I'm here for you—always." Creating a non-judgmental space.
  • Clear: Direct, simple language. Navigating identity can be complex; our UI shouldn't be.
  • Affirming: Validating user experiences and identities without reservation.
  • Protective: Explain privacy choices plainly without promising that every feature is offline or end-to-end encrypted.

We Are Not

  • Clinical/Cold: Avoid overly medicalized or detached language.
  • Presumptive: Never assume a user's pronouns, identity, or journey stage.
  • Pushy: Never force disclosure or push users toward resources they aren't ready for.
  • Diagnostic: The AI never diagnoses; it only observes, reflects, and supports.

The "Cosmic Q" Render

The primary logomark is a 3D, glossy 'Q' containing a cosmic nebula effect. It represents the infinite possibilities of self-discovery, fluidity, and the depth of inner reflection.

  • Colors: Deep indigo base with vibrant magenta, cyan, and gold nebula swirls.
  • Texture: High-gloss glass/liquid appearance with specular highlights.
  • Usage: Best used on dark backgrounds (`#0F091F`) with `mix-blend-mode: screen` or `lighten` to allow the black background of the render to drop out.

Application Architecture

Based on the Q Intelligence repository structure.

Frontend (React / Vite)

  • Framework: React 18+ (TSX)
  • Styling: Tailwind CSS v3
  • State: React Context
  • Navigation: Authenticated SPA views

AI Integration

  • Local AI: WebLLM (In-browser)
  • Memory: Vector search
  • Safety: Prompt injection guards

Backend (Supabase)

  • Auth: Supabase Auth
  • Database: PostgreSQL
  • Security: Strict RLS Policies
  • Server: Express / Node.js

Testing & DevOps

  • E2E: Playwright
  • CI/CD: GitHub Actions
  • Hosting: Vercel
