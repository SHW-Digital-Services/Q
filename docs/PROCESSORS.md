# Processor Register

## 1. Purpose

This Processor Register identifies the third-party processors and sub-processors used by **Q Intelligence**, operated by **Scott Harvey-Whittle trading as SHW Digital Services**, in the provision of our services.

This register supports transparency under applicable data protection legislation, including the UK GDPR and, where applicable, the EU GDPR.

---

# 2. Current Sub-processors

| Provider | Purpose | Data Processed |
|----------|---------|----------------|
| Supabase | Authentication, PostgreSQL database, object storage, user sessions | Account information, authentication data, uploaded files, application data |
| OpenAI | Optional hosted AI model processing selected by the user | PII-masked prompts and context submitted for hosted processing, AI responses |

WebLLM performs inference on the user's device and is not used by Q as a processor of prompts on Q's behalf. A user's browser contacts model-distribution infrastructure to download the WebLLM runtime and model assets; those services may process ordinary network metadata under their own policies.
| PayPal | Subscription billing and payment processing | Billing information, payment identifiers, transaction records |

---

# 3. Infrastructure Providers

Q Intelligence may also rely upon reputable infrastructure and service providers for functions including:

- DNS and networking;
- content delivery;
- email delivery;
- security monitoring;
- application hosting;
- backup services;
- logging and diagnostics.

Only providers necessary for the secure and reliable operation of the Service are engaged.

---

# 4. Selection Criteria

Before engaging a processor, we consider factors including:

- security practices;
- reliability;
- privacy compliance;
- contractual safeguards;
- operational suitability;
- reputation;
- legal obligations.

---

# 5. Processor Obligations

Where applicable, processors are expected to:

- process data only on authorised instructions;
- implement appropriate security measures;
- maintain confidentiality;
- assist with applicable legal obligations;
- notify relevant security incidents where contractually required.

---

# 6. International Data Transfers

Some processors may process data outside the United Kingdom.

Where required by applicable law, appropriate transfer safeguards will be implemented before international transfers occur.

Such safeguards may include:

- adequacy regulations;
- approved contractual clauses;
- recognised international transfer mechanisms;
- other lawful transfer mechanisms.
